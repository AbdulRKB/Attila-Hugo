# Attila Hugo 

A fast, customizable Hugo theme adapted from the popular Attila design from [Ghost](https://ghost.org/themes/attila/). Built with performance and minimal configuration in mind.

## Quick Start

### 1. Requirements

Ensure you have [Hugo](https://gohugo.io/installation/) installed (extended version is recommended).

### 2. Installation

Since this repository includes both the theme and a pre-configured starter site, you can simply clone it to get started immediately:

```bash
git clone https://github.com/AbdulRKB/Attila-Hugo.git my-blog
cd my-blog
```

### 3. Configuration

Edit the `hugo.toml` as needed.

> **Note:** Place your images like `avatar.png` and `cover.jpg` in your site's `/static/images/` directory.

### 4. Running Locally

Start the Hugo development server:

```bash
hugo server -D
```

Your site will be available at `http://localhost:1313/`.
